Se o Windows oferecer a Microsoft Store, o link deste botão ainda não está registrado: rode npm run daily:start uma vez na pasta do Claudio’s Club. Ele registra o link (sem atalho) e, daí em diante, se refaz a cada subida.

    Opcional: disco mais rápido

    O antivírus do Windows (Defender) verifica cada arquivo que o Claudio’s Club, o git e os testes abrem, e num HD isso pesa no disco. Tirar estas pastas da verificação em tempo real alivia o disco. É opcional e quem roda é você: copie o comando e cole no PowerShell aberto como administrador. A página nunca roda nada.
